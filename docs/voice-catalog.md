# XTTS Profile Catalog

Curated profile catalogs live in:

- `addon/synthDrivers/maxlogic_xtts_v2/catalog.json`
- `addon/synthDrivers/maxlogic_xtts_v2/community_catalog.json`

Each entry may point to a downloadable XTTS profile bundle and metadata such as display name, language, and gender.

The initial scaffold ships with empty catalogs so the add-on structure is ready before curation work begins.
