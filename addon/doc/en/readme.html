MaxLogic XTTS v2 for NVDA

MaxLogic XTTS v2 is an NVDA add-on that adds a separate XTTS v2 speech synthesizer under the name MaxLogic XTTS v2.

  • Separate NVDA synth: MaxLogic XTTS v2
  • One-click runtime setup from the voice manager
  • Voice manager with Installed, Hugging Face, Official, Community, Extract Sample, and Speech Cache tabs
  • Five bundled CC0 starter voices
  • Curated on-demand voice downloads from legal upstream sources
  • Live Hugging Face search for XTTS-compatible repos with playable sample audio
  • Local XTTS profile install from reference audio, XTTS conditioning files, or zip bundles
  • Direct .pth install validates compatibility before accepting the file
  • Extract a short XTTS-ready sample from a longer recording with start/end markers
  • Edit extraction sources safely by deleting marked snippets from a temporary working copy
  • Keyboard shortcuts for Extract Sample transport, markers, preview, deletion, and saving
  • Speech cache for repeated short utterances

User profiles are stored in %APPDATA%\nvda\maxlogicXTTSv2\voices.

Install the add-on normally. The installer bootstraps the helper runtime automatically. If the helper runtime is missing or needs repair, open NVDA menu -> MaxLogic XTTS v2 voice manager... and use Set up XTTS runtime. The setup step installs the latest released Coqui TTS package from PyPI.

Bundled starter voices: Gosia, Darkman, Kathleen, Joe, and Kerstin.

The Official tab uses curated CC0 OHF Voice samples. The Community tab adds curated voices from Thorsten-Voice and Kyutai.

The Hugging Face tab searches live XTTS-related repos that expose playable sample audio, lets you preview those samples, and installs from the sample audio rather than trusting arbitrary checkpoint files.

Direct local .pth install is supported, but only when the helper can load the file as a valid XTTS voice-conditioning file. Invalid or unrelated PyTorch checkpoints are rejected.

The Extract Sample tab copies each selected source recording to a temporary working file before editing. Use the Start marker and End marker to select interruptions, then use Delete snippet to remove that range from the working copy. Playback, preview, and saving use the working copy; the original recording is not changed. Temporary working files are deleted when another source recording is selected or the voice manager closes. Large uncompressed .wav sources stream directly for responsive playback and seeking when the system media control cannot load them.

The Extract Sample panel reports whether the selected range is shorter than, longer than, or within the recommended 10 to 30 second XTTS sample range. Shortcuts: Ctrl+O browse, Ctrl+P play or pause, Ctrl+K stop, Ctrl+Left/Ctrl+Right move 5 seconds, Ctrl+Shift+Left/Ctrl+Shift+Right move 30 seconds, Ctrl+1 set start, Ctrl+2 set end, Ctrl+R preview selection, Ctrl+D delete snippet, and Ctrl+S save.
