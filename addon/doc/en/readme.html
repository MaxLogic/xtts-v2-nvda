MaxLogic XTTS v2 for NVDA

MaxLogic XTTS v2 is an NVDA add-on that adds a separate XTTS v2 speech synthesizer under the name MaxLogic XTTS v2.

  • Separate NVDA synth: MaxLogic XTTS v2
  • One-click runtime setup from the voice manager
  • Voice manager with Installed, Hugging Face, Official, Community, Extract Sample, and Speech Cache tabs
  • Five bundled CC0 starter voices
  • Curated on-demand voice downloads from legal upstream sources
  • Live Hugging Face search for XTTS-compatible repos with playable sample audio
  • Local XTTS profile install from reference audio, XTTS conditioning files, or zip bundles
  • Direct .pth install validates compatibility before accepting the file
  • Extract a short XTTS-ready sample from a longer recording with start/end markers
  • Edit extraction sources safely by deleting marked snippets from a temporary working copy
  • Save the current marked snippet or preserve the edited working copy as a separate audio file
  • Keyboard shortcuts for Extract Sample transport, markers, preview, deletion, and saving
  • Speech cache for repeated short utterances
  • Streamed uncached XTTS speech when the helper runtime supports it

User profiles are stored in %APPDATA%\nvda\maxlogicXTTSv2\voices.

Install the add-on normally. The installer bootstraps the helper runtime automatically. If the helper runtime is missing or needs repair, open NVDA menu -> MaxLogic XTTS v2 voice manager... and use Set up XTTS runtime. The setup step installs the pinned helper runtime tested with this add-on.

The bootstrap script installs Python packages pinned for the tested XTTS streaming stack: coqui-tts==0.24.3, transformers==4.46.1, numpy<2, and PyTorch/Torchaudio 2.11.0 for the selected provider. Auto setup prefers Python 3.11 when available because that is the tested environment.

Normal NVDA speech cancellation stops current audio without restarting the XTTS helper. This keeps the warmed CUDA runtime available for the next utterance; the helper is closed when the synth is terminated or NVDA switches away from it.

XTTS is still a large neural voice-cloning model, so uncached text is much slower than classic screen-reader synths. With the pinned helper runtime, the driver streams generated audio chunks as they become available, then relies on the persistent speech cache for repeated UI text. If a different helper runtime does not report streaming support, the add-on falls back to full-buffer synthesis.

Bundled starter voices: Gosia, Darkman, Kathleen, Joe, and Kerstin.

The Official tab uses curated CC0 OHF Voice samples. The Community tab adds curated voices from Thorsten-Voice and Kyutai.

The Hugging Face tab searches live XTTS-related repos that expose playable sample audio, lets you preview those samples, and installs from the sample audio rather than trusting arbitrary checkpoint files.

Direct local .pth install is supported, but only when the helper can load the file as a valid XTTS voice-conditioning file. Invalid or unrelated PyTorch checkpoints are rejected.

The Extract Sample tab decodes each selected source recording, including .m4a files when ffmpeg is available, to a temporary WAV working file before editing. Use the Start marker and End marker to select interruptions, then use Delete snippet to remove that range from the working copy. Use the 3-second marker preview buttons to listen before or after the start and end markers; Preview selection starts the marked range and stops it when pressed again. Playback, preview, and saving use the working copy; the original recording is not changed. Edit Current position directly to seek; the typed value is applied when the field loses focus or when Enter is pressed. Temporary working files are deleted when another source recording is selected or the voice manager closes. Large uncompressed .wav sources stream directly for responsive playback and seeking when the system media control cannot load them.

Use Save current snippet as audio to export the selected range as a .wav, or Save edited audio as... after deleting snippets to preserve the modified WAV working copy.

The Extract Sample panel reports whether the selected range is shorter than, longer than, or within the recommended 10 to 30 second XTTS sample range. Shortcuts: Ctrl+O browse, Ctrl+P play or pause, Ctrl+K stop, Ctrl+Left/Ctrl+Right move 5 seconds, Ctrl+Shift+Left/Ctrl+Shift+Right move 30 seconds, Ctrl+1 set start, Ctrl+2 set end, Ctrl+R preview selection, Ctrl+D delete snippet, Ctrl+E save current snippet, Ctrl+M save edited audio, and Ctrl+S save profile.
