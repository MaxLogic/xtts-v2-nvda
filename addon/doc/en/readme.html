MaxLogic XTTS v2 for NVDA

MaxLogic XTTS v2 is an NVDA add-on that adds a separate XTTS v2 speech synthesizer under the name MaxLogic XTTS v2.

  • Separate NVDA synth: MaxLogic XTTS v2
  • One-click runtime setup from the voice manager
  • Voice manager with Installed, Official, Community, and Speech Cache tabs
  • Five bundled CC0 starter voices
  • Curated on-demand voice downloads from legal upstream sources
  • Local XTTS profile install from reference audio or zip bundles
  • Speech cache for repeated short utterances

User profiles are stored in %APPDATA%\nvda\maxlogicXTTSv2\voices.

Install the add-on normally. The installer bootstraps the helper runtime automatically. If the helper runtime is missing or needs repair, open NVDA menu -> MaxLogic XTTS v2 voice manager... and use Set up XTTS runtime. The setup step installs the latest released Coqui TTS package from PyPI.

Bundled starter voices: Gosia, Darkman, Kathleen, Joe, and Kerstin.

The Official tab uses curated CC0 OHF Voice samples. The Community tab adds curated voices from Thorsten-Voice and Kyutai.
