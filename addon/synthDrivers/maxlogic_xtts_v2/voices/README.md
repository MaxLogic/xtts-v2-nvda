Packaged XTTS voice profiles can be stored here as one directory per profile.

Each profile directory should contain at least one reference audio file and a `profile.json`.

The repository currently bundles a small CC0 starter set sourced from OHF Voice:

- `de_de_kerstin`
- `en_us_joe`
- `en_us_kathleen`
- `pl_pl_darkman`
- `pl_pl_gosia`
